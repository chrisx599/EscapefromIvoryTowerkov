# 学阀 · 科研概率搜打撤

当前版本 v0.7.0，只保留正式科研工位和概率远征。无需 AI 模型或 Phaser。

```sh
npm install
npm start
```

使用 Node.js 22 或以上，打开 [游戏](http://localhost:5173)。可参考 `.env.example` 设置 `PORT` 或 `GAME_SAVE_DIR`；真实配置与存档保持在本地，不进入 Git。

## 玩法

- 查看课题缺口，选择地点、新手／标准／挑战难度，配好五槽装备与最多三件补给。
- 材料按地点自然出现。搜索会花心力、积累危险；事件选择会影响收获和撤离。
- 前两次有效搜索内至少一次事件；处理后冷却一次搜索，每局最多四次事件。
- 撤离后整理收获，再投入实验、投稿、返修、论文录用与晋升。
- 已穿戴装备不占仓库，备用副本占用。仓库可从 40 扩至 120，每次增加 20。
- 默认只显示材料发现机会、探索压力和完整带回把握；详细概率可展开查看。

当前入口为 `public/index.html`，规则主规格为 [REVAMP.md](REVAMP.md)，研究规则为 [RESEARCH.md](RESEARCH.md)，文档导航为 [SPEC.md](SPEC.md)。

## 存档与恢复

默认存档位于 `data/saves/`。刷新和阅读不推进远征；同一请求重试不重抽或重复扣款。当前远征保留原随机状态与行动进度。

停用版本的存档在首次读取时一次性回收已有行李和应归还装备，保留经费、仓库、论文和课题，回到正式工位。已结算的奖励不再领取。迁移前保留原文件备份，格式损坏的文件不会被重置。
