# 像素素材

当前正式工位复用本目录 PNG，透明背景与像素缩放保留。

| 素材 | 用途 |
|---|---|
| student-directions.png | 玩家头像，按 2×2 图集裁取一帧 |
| scholar.png | 人物事件 |
| poster-board.png | 学术交流地点与开源机会 |
| research-desk.png | 研究、实验与设备事件 |
| locker.png | 实验室地点与资源事件 |
| taxi.png | 撤离与路线事件 |
| items/*.png | 仓库、商店、装备、补给与结算图标 |

`crate-states.png` 与 `conference-floor.png` 作为备用像素素材保留，不参与当前玩法。物品 ID 与图像映射见 `public/item-art.js`，物品生成记录见 [items/README.md](items/README.md)。
