# v0.9.0 · 搜索、背包、撤离

这一轮按玩家反馈收回了先前增加的决策负担。游戏中的随机性留在规则里，不要求玩家先阅读概率、流派说明或结果预告。

## 玩家看到的远征

- 一个“搜索”按钮，一个“撤离”按钮；不再选择谨慎／常规／深入模式
- 背包常驻在主要区域，直接看见实时物品；点击物品可使用、放下或施展已有专长
- 心力用小心形与进度条表示，背包只显示当前占用和容量
- 遭遇只留一句短情境和几个中性的短按钮，不标注把握大小，不提供可能结果
- 点击后显示一句实际结果、心力变化和新物品图标；新入包物品短暂亮起，尊重减少动态效果设置
- 不再展示深入程度、临时影响解释、现场预测、队伍说明或持续行动日志
- 背包装不下时，在眼前处理新发现，再继续搜索或撤离

概率与定性把握都不会作为按钮说明或隐藏展开项展示。出发准备页也不再显示发现或撤离预测。

## 随机结果

新远征启用独立的遭遇规则版本。事件出现时，确定性的存档随机数生成器生成并保存该次遭遇的隐藏变化与选项顺序。玩家点选后再结算，不会因阅读、刷新或网络重试重新抽取。

普通选择不要求先计算哪一项花多少材料，也不会因为空背包而只剩一个可选方案。相似的短动作可以遇到不同结果：得到物品、缓和局面、恢复心力，或者遇到小挫折、消耗心力、增加返程压力。数值有边界，长期装备、已发表论文和生涯身份不会被随机抹除。

已有校园故事仍会延续选择，成功和受挫分别留下符合实际的后续。独特章节奖励只结算一次。旧故事完成后留下的普通事件解法继续有效，但不把隐藏成功率告诉玩家。

## 兼容性

- 生涯存档仍兼容原有版本，云端数据库结构不变
- 已有的进行中远征保留其已生成的事件规则；新界面立即适用，下一次出发启用新的隐藏变化
- 旧 API 的搜索模式 ID 继续接受，避免破坏进行中的远征、重试回执和外部调用；玩家界面只发送普通搜索
- 晋升、奖励、流派、仓库和研究系统保留；远征里不再另设流派说明面板

## 验证

引擎测试覆盖固定种子复现、不同种子的真实结果差异、状态上下限、故事回调、空背包选择、旧存档、重试不重复结算。浏览器测试覆盖背包和搜索同屏、无概率和结果预告、手机触控、满包处理、物品实际变化、断网恢复，以及原有研究、仓库、装备与晋升流程。
