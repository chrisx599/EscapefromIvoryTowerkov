# v0.8.0 · 校园奇遇与科研流派

> 历史版本记录。当前远征界面和事件选择已按 [v0.9.0](GAMEPLAY_V5.md) 简化；以下提前描述风险、成本或后续的界面说明不再适用。

本轮重点是让选择留下可见后果，以及让晋升获得新的行动方式。仍然是内置规则游戏，不调用模型，也没有现实时间等待、签到压力或付费机制。

## 校园奇遇

三条原创两幕故事：审稿打印机觉醒、公章证明它自己、院长猫的署名要求。第一幕决定你如何回应，第二幕读取已经发生的选择，提供相应的解决方式。投入材料、花心力、动用人脉与婉拒都有不同的结果；没有把所有选项包装成同一种奖励。

- 使用存档中的确定性随机状态选择故事，刷新页面不重抽
- 未完成的后续优先于新的故事；继续搜索时遵守事件冷却，不会连续轰炸玩家
- 可以提前撤离。未完故事随生涯保存，后续远征仍记得你之前的选择
- 故事进展不属于背包战利品，撤离失败也不会失忆
- 每幕只能推进一次，已结算的独特奖励不能重复领取
- 已完成的结局会为相应的普通事件提供有条件的新办法，让故事结束后的选择仍然有用
- 故事可以婉拒，代价、已知影响与具体后果由界面和事件结果说明

本次故事是有限的手工分支内容，不宣称具有无限生成剧情。已有地点、装备、研究方向、搜索方式、局势和临时影响继续共同决定一局的走向。

## 晋升有所得

申请晋升仍要求论文、成果和能力达标；第一篇论文的门槛没有提高。晋升后立即到账一笔支持经费，并列出真正解锁的设备、课题或地点。奖励按生涯阶段只发一次，刷新、请求重试、确认提示都不会重新发钱。

硕士至院士的支持经费依次为 180、220、280、340、400、460、520、600。经费直接到账，仓库满不会吞掉奖励。

首次晋升可以永久选择一种科研流派：

- **档案派**：每次远征封存一件背包研究材料，在任何撤离结果下保留。可以和备份设备分别保护材料；新课题初始质量获得稳定加成
- **联络派**：每次远征可用 1 点人脉稳妥解决一次符合条件的人物交涉；故事交涉仍留下相应分支。录用论文获得额外支持经费
- **巧匠派**：每次远征将一份数据、源码或方向情报改装为一张算力卡；实验质量获得稳定加成

流派在博士后与教授阶段提升研究专长，主动能力仍为每次远征一次。选择说明明确其长期性，不能反复切换领取多个流派效果。

## 界面

晋升时显示简洁的任命反馈、已到账奖励与流派选择。选定后收成一条可展开的专长记录。远征只显示当前流派是否可用；材料技能在选中的背包物品上操作，交涉技能在对应事件内出现。结算只展示本局留下的故事后果，完整记录放在生涯档案。

风险与把握仍然采用定性措辞。物品数量、经费消耗、质量进度等确定资源数值正常显示。

## 存档与安全边界

继续兼容版本 2 生涯和版本 3 正式远征。新增故事字段有独立版本，旧的进行中远征保持原规则，回工位后的新远征加入故事。旧的硕士及以上存档可以补选流派，但不会追溯发放以前的晋升经费。

本地服务器与托管版本使用相同玩法代码，分别保持原有独立存档。托管数据库不需要表结构迁移。

## 验证

`npm test` 包括原有规则回归、故事分支与前置条件、固定种子复现、旧存档、一次性晋升奖励、流派限制、跨局结算和批量首晋升路径。

`npm run test:browser` 检查原有仓库、断网恢复、研究和远征流程。`npm run test:gameplay:browser` 覆盖新增的真实晋升、流派、故事回调与响应式体验。测试使用隔离存档，不接触玩家的真实进度。
