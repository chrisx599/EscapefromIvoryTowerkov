# 界面减负与远征玩法优化

日期：2026-10-04。基于主分支 `a2c057a7fe6ac656551c07eca414f8109fad5db8`，在第一轮工位视觉优化上继续迭代。

## 玩家会看到什么

- 保留深绿、纸色与像素素材，默认工位只显示经费、阶段、简短材料缺口、目的地和难度
- 装备、补给、材料倾向与地点版图按需展开；完整身份和生涯统计移到档案
- 出发配置与「开始远征」保持可见；远征将搜索/撤离放在首屏，心力、背包和形势一眼可读
- 概率百分比与计算明细从界面移除，折叠内容、物品提示、事件选择、旧日志也使用定性描述；仍明确显示资源消耗和可能后果
- 事件先呈现行动、把握和成本，后果可展开；背包和日志默认收起，出现装不下的发现时自动打开背包
- 新远征重置临时展开状态；装备选择支持键盘打开、Escape 关闭和焦点返回；保留断网重试与异常存档恢复提示

## 远征变化

- 谨慎摸排：少些收获与波折，并逐渐靠近出口
- 常规搜索：兼顾收获与返程
- 深入搜寻：增加发现和遭遇，但风险增长更快、返程距离更远
- 每两次搜索进入一段新环境：交换区、侧廊、演示间、核查区或资料区，分别影响材料类型、发现机会、遭遇类型与返程
- 事件成功或受挫留下持续两次搜索的指路、线索、设备或路线影响；做选择之前可以查看这些后果

随机变化使用现有种子随机源，读取与刷新不重抽。所有概率有上下界，撤离结果总和保持一致。搜索方式在实际搜索时一次性提交，切换界面选项不消耗心力，也不能凭空改变撤离结果。

## 存档兼容

旧远征缺少新字段时使用中性默认值，不重置人物、物资或正在进行的远征。新增环境、返程距离和短期影响保存在原有远征数据中。没有数据库表结构改动。

本地 Node 版与独立托管 Worker 版使用同一套游戏规则；托管试玩使用独立云端存档。

## 本地运行与验证

要求 Node.js 22+。

```sh
npm ci
npm start
npm test
npm run test:browser
```

默认地址为 http://localhost:5173，可通过 PORT 修改端口，通过 GAME_SAVE_DIR 指定存档目录。不要用测试存档覆盖玩家存档。

浏览器测试优先使用 CHROME_PATH，没有系统浏览器时可安装项目锁定版本：

```sh
npx playwright install chromium --only-shell
CHROME_PATH=/absolute/path/to/headless_shell npm run test:browser
```

## 第三轮：研究与远征更直观（2026-10-04）

- 研究工位以当前课题为中心：真实研究流程、论文质量/目标、已用实验轮数、带物品图标的材料准备、明确的下一步操作
- 缺材料时直接指向商店、仓库或远征；待审稿、审稿通过和满足晋升条件时分别突出对应操作
- 研究方向、材料整理、其他课题、晋升条件和论文历史按需展开，展开状态在状态刷新后保留；放弃课题须确认投入不返还
- 远征将现有像素人物、场景物件和当前遭遇放进同一现场示意，心力/背包用实际数值条显示，形势继续只显示定性词语
- 深入程度严格对应已有存档中的「靠近出口／已入内场／深入腹地」，不构造地图、路线或虚构进度
- 当前需要处理的事件、整理发现和主要搜索/撤离操作与现场并排展示，手机上下相邻；最新结果直接反馈在现场下方

本轮仅改变展示与交互组织，不改变第二轮的远征规则、研究规则或存档。

新增展示模块：`public/research-workbench.js` / `.css` 与 `public/field-scene.js` / `.css`。浏览器回归增加多种研究状态、直观层级、实际状态条、现场/决策位置、窄屏以及放弃确认的验证。
