# 科研工位 UI 优化交付

基于 main 提交 `a2c057a7fe6ac656551c07eca414f8109fad5db8`，日期 2026-10-04。

## 改动范围

- 延续科研题材和现有像素素材，以深绿、纸色、少量黄铜色统一工位、远征和结算界面
- 收起重复玩法提示和区块标题，整合研究者/经费/仓库/生涯摘要，保留小屏上的全部统计
- 强化目的地场景、课题缺口与难度层级，加入直接打开研究区的快捷入口
- 备战时固定显示出发配置、费用和「开始远征」按钮；切换工作区或进入远征后隐藏
- 装备格子保持紧凑正方形，分离名称与图标；没有选中物品时不再显示多余的空详情框
- 修复远征撤离概率三联卡被挤在父网格单列中的布局问题
- 装备选择器打开后移入键盘焦点，Escape 关闭并返回原槽位；支持减少动态效果偏好
- 工位反馈显示在导航附近，避免滚动后看不到购买/升级/错误结果；异常远征数据仍使用全局可见恢复提示
- 使用真实身份名称解释商店锁定原因；为风险值添加可访问的 meter 语义
- 测试入口支持 CHROME_PATH、Linux 和 macOS 系统浏览器，保留 Windows Chrome/Edge 路径

未更改掉落概率、经济、难度、存档格式或服务端玩法；没有新增运行时依赖或外部字体请求。

## 本地运行

```sh
npm ci
npm start
```

要求 Node.js 22+，默认地址 http://localhost:5173 。可以通过 PORT 修改端口，通过 GAME_SAVE_DIR 指定存档目录。不要把已有玩家存档覆盖到测试目录。

## 验证

```sh
npm test
npm run test:browser
```

浏览器测试优先使用 CHROME_PATH。没有系统浏览器时，可安装项目锁定版本的 Playwright 浏览器；受限环境可使用 headless shell：

```sh
npx playwright install chromium --only-shell
CHROME_PATH=/absolute/path/to/headless_shell npm run test:browser
```

本次验证：72 项逻辑/API 测试全部通过；完整隔离浏览器回归通过，覆盖仓库扩容、装备交换、断网重试、搜寻与事件、撤离、论文录用和晋升。新增覆盖 320/360/701/768/900px 全部工位标签、装备选择器键盘打开/关闭、真实单列布局、异常远征状态与同步恢复、320/390/768/1440px 概率面板。

截图来自实际浏览器运行的隔离测试存档，人物身份由游戏随机生成。交付包 review/ 含原版与新版截图、测试日志；不含真实玩家存档、浏览器缓存、node_modules 或凭据。

## 文件说明

- public/field-station.css：独立的整体视觉层，保留基础组件样式
- public/index.html：页面层级、行动栏、语义和图标
- public/probability-app.js：界面反馈、焦点、摘要和错误恢复
- public/favicon.svg：简单塔形图标
- tools/probability-browser.mjs：跨平台浏览器选择和新增 UI 回归
- .gitignore：排除预览存档与本地浏览器缓存

此版本在隔离环境运行并验证，不包含生产环境的部署配置。上线前应在目标环境设置持久存档目录并确认备份方案。
