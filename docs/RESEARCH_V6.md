# v0.10.0 · 研究、发表、职称

手工整理材料与研究方向选择已被 [v0.11.0 简化规则](RESEARCH_V7.md) 取代；其余实验、审稿、晋升规则仍适用。

研究界面只保留当前职称、当前课题、实际进度和下一步。派系选择与主动派系技能已退出玩家界面。晋升立即发放一次性经费，研究支持随职称自动生效，不再要求三选一。

## 简单操作，内部有变化

继续使用原有循环：立项 → 实验 → 投稿 → 审稿 → 返修或录用 → 晋升。课题、装备、论文与经费沿用原存档，不新增配置菜单、风险标签或结果预测。

- 实验：工程和研究能力、已装备设备、整理材料留下的笔记、方向契合、该方法的实际练习、已有质量与证据共同影响结果。稳定复现和实验波动有不同的质量与证据增量；每轮都会留下学习积累，不倒扣旧论文或职称。
- 审稿：论文质量、可复现证据、表达能力、方法经验、材料准备和方向契合共同决定评审基础，再叠加小幅、保存下来的评审差异。同样质量的论文不再一定得到相同结果。
- 晋升：仍须满足论文、成果与能力条件，另外认可代表作或方法积累中的任一路径。已有成果不会被消耗；晋升本身是满足条件后确定兑现的奖励，不反复抽取资格。
- 职称奖励：一次性经费继续按原阶段发放，硕士、博士后与教授阶段提升自动研究支持。已解锁地点和设备保留。

主界面不显示概率、把握或录用质量目标。当前质量和实验轮数只描述已完成的工作；审稿后才给一句实际结果与缺口。缺材料、设备或能力时，显示真实缺口及补齐入口。

## 材料和修补

整理未发表材料或方向情报时，除了原有的一换一材料转换，还留存对应整理笔记。下一项使用该类材料的课题会投入有限笔记；不会暗中扣除额外库存。每次立项和实验只扣界面列出的经费、材料与算力。

新课题自动采用职称、当前设备和能力共同支持的最高规模；晋升后仍可用基础设备做基础课题。已开始的课题保留原规模，不因职称变化提高进行中的成本或门槛。

取消旧版六轮实验上限。返修仍需真实补实验才能再投稿，不能反复点击审稿重抽。实验质量和证据单调累积，经验保留，有可达的修补终点。即使经费不足，零费用的学术交流仍能搜集、出售材料补充研究资源。

## 旧存档

- 保留职称、论文、经费、仓库、装备、研究进度、审稿状态和随机数状态；已获录用资格不重审
- 原档案派、巧匠派和联络派已经获得的研究加成，按原职称等级转换为自动保留的研究支持，不需选择、不会叠加迁移或补发晋升经费
- 历史论文沿用已有质量补齐证据资料；旧课题按已完成轮次恢复保守证据。缺少方法积累字段的旧档案，按每篇已完成论文至少两轮实验及当前课题的实际轮次恢复保守经验，之后以存储值为准，不重复推算或伪造额外奖励
- 新远征不再生成派系技能。旧远征已经封存或保护的物品仍按原规则结算，界面不再要求操作派系按钮
- 同一请求重试返回原回执，实验和审稿不重新抽取，不重复扣款或领奖；数据库结构不变

## 验证重点

固定种子下逐一改变因素检查真实因果影响；上下界、实验失败学习、审稿多种结果、有限修补、全职称可达性、旧派系迁移、重复请求与并发扣费、晋升奖励一次性。浏览器覆盖材料不足、立项、实验、投稿、返修、录用、晋升、旧存档和手机布局，并回归单搜索与常驻背包。
