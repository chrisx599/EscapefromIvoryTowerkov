# v0.11.0 · 少两个步骤，保留真正的成长

研究工位不再有「整理材料」和「研究档案」面板，也不再选择四种研究方向。保留当前职称、三项属性、当前课题与一个下一步按钮；其他课题和晋升条件继续按需展开；已录用论文只显示累计篇数。

## 属性直接看得懂

- 工程：参与实验结果与课题能力门槛
- 研究：参与实验质量、证据积累、课题门槛与晋升
- 表达：参与审稿结果与晋升

属性展示当前等级，仍通过实验、投稿、录用和实际远征逐步增长。这里没有新增加点菜单、概率标签或结果预告。设备条件仍在真正缺少时提示，研究日不再作为玩家需要关注的属性展示。

## 材料直接投入课题

立项时优先使用仓库已有的标准研究材料；不足的部分可以直接使用等价原料：

- 未发表结果可直接用于需要数据包的课题
- 预印本草稿、内幕消息、基金重点可直接用于需要方向情报的课题

界面显示可用数量；使用替代原料时，同时显示具体消耗哪一份。只有点击立项并满足全部条件，才按计划扣除原料与经费。不会在读档或出征结算时批量转换库存，不改变尚未投入课题的物品及卖价，不额外扣手续费。缺少源码或算力仍可通过远征、商店获得。

直接使用原料会自动完成原有的必要准备。新课题默认具备方向契合，不必先切换方向；课题类型、设备、能力、经验、已有质量和证据仍共同影响实验与审稿。不会把多因素研究退回固定结果。

## 旧存档与兼容性

已有职称、论文、经费、库存、装备及派系迁移后的研究支持均保留。

- 原有准备笔记仍存在，匹配的新课题会自动按需使用一次；原料准备和旧笔记不会对同一份输入重复计算，原料已有准备效果时不浪费旧笔记
- 进行中的课题保留原方向契合、准备加成、质量、证据、随机状态、规模及审稿状态
- 旧方向仅作为历史元数据，不再提供选择入口；新课题不因旧方向不同而处于劣势
- 手工整理、方向切换的旧操作不再接受，不会扣资源或推进随机状态
- 同一立项请求重试不重复消费；素材不足或经费不足时，原料、笔记和经费一并保持不变

当前多因素实验、审稿和概率晋升的数值与恢复规则见 [BALANCE.md](../BALANCE.md)。[RESEARCH_V6.md](RESEARCH_V6.md) 保留为旧版设计记录，不再作为当前概率规则。
